# Privacy Policy — FAMILY

**Last updated: October 26, 2026**

FAMILY is a personal, single-user script operated by Georgiy Tyurin ("I", "me") to upload my own videos to my own YouTube channel (https://www.youtube.com/@AIHYPE_BOT). It is not offered to the public and has no other users.

## What the application accesses

When I sign in with my own Google account, the application uses the YouTube Data API v3 with the following permissions:

- `youtube.upload` — to upload my own videos;
- `youtube` — to set video metadata, schedule publishing and set thumbnails on my own channel.

It calls `videos.insert`, `thumbnails.set` and `channels.list` (to confirm which channel is connected).

## What data is collected and how it is used

- The application accesses only the account and channel of its owner (me).
- It does not collect, store, sell, share or analyze personal data of any other person, including other YouTube users, viewers or commenters.
- The only data kept is an OAuth access/refresh token for my own account, stored locally on my computer in a private file. It is used solely to publish my own videos and is never transmitted to any third party.
- No analytics, advertising or tracking tools are used.

## Sharing and disclosure

I do not share, transfer or sell any data to third parties.

## Google API Services

The application's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. It is also subject to the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

## Data retention and revoking access

The local token is kept only as long as the application is used. I can revoke the application's access at any time at https://myaccount.google.com/permissions and delete the local token file.

## Children's content

The channel publishes family-friendly content, which is declared as "made for kids" and as AI-generated where applicable. The application does not collect any personal information from children or from viewers.
