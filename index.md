# FAMILY

FAMILY is a personal, single-user tool that uploads the owner's own videos to the owner's own YouTube channel: [https://www.youtube.com/@AIHYPE_BOT](https://www.youtube.com/@AIHYPE_BOT).

It uses **YouTube API Services** (YouTube Data API v3) to upload videos, schedule their publication and set thumbnails on that single channel. It is not offered to the public and has no other users.
